# 🌱 My Garden

## Opis projekta

**My Garden** je web aplikacija razvijena u sklopu kolegija **Programsko inženjerstvo** na Fakultetu informatike u Puli.

Aplikacija omogućuje korisniku organizaciju vlastitog vrta kroz vođenje evidencije biljaka, pregled enciklopedije biljaka, zapisivanje bilješki u vrtni dnevnik te spremanje recepata inspiriranih vlastitim urodom.

## Funkcionalnosti

- registracija i prijava korisnika
- upravljanje vlastitim biljkama
- pregled detalja biljaka
- pregled enciklopedije biljaka
- pretraživanje i filtriranje biljaka
- vođenje vrtnog dnevnika
- dodavanje, uređivanje i brisanje zapisa u dnevniku
- spremanje i upravljanje receptima
- pohrana korisničkih podataka u Firebase Firestore bazu podataka
- responzivno korisničko sučelje
